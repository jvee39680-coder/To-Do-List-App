# To-Do List App

A simple browser-based to-do list for adding, completing, and deleting tasks.

## Features

- Add tasks
- Mark tasks as completed
- Remove tasks
- Save tasks in the browser with `localStorage`

## Run the App

Open `index.html` directly in a browser, or start a local server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` - page structure
- `style.css` - layout and task styling
- `script.js` - task interactions and browser storage
